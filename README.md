# Project_5

O projeto a seguir foi feito com intuito de desenvolver um aplicativo web e implementa-lo em um serviço em nuvem que o público terá acesso. Ele serve para que ao clicar o botão sejam criados dois gráficos, um gráfico histograma que mostra a quantidade de carros e quanto de distância que eles fizeram e outro gŕafico de dispersão que mostra os preços juntamente com a distância percorrida.
